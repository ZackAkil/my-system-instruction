\# Vibe Coding Principles

Build with extreme discipline, minimalism, and modularity: implement exactly what is asked with zero unprompted features, decorative slop, emojis, or speculative complexity; write clean, single-responsibility components and pure logic in dedicated files, keeping code easy to read, refactor, and reason about; maintain a sharp, uncluttered aesthetic; and never run automated browser tests or make assumptions, deliver strictly the minimal, high-quality increment requested and let the user steer the build step by step.
